# SKALA Front legacy shell

이 공개 저장소는 퇴역한 SKALA Front 교육 과제의 과거 GitHub Pages 주소를 안전한 종료 안내로 유지합니다.

- 실제 과거 소스 정본은 비공개 `AgenticLab-SH/skala-frontend`에 보존됩니다.
- 과거 Cloudflare Pages 프로젝트와 custom domain은 현재 존재하지 않습니다.
- 이 셸은 다른 주소로 리디렉션하거나 로그인·데이터 입력을 받지 않습니다.
- 중앙 서비스 장부는 `skala-frontend`를 `retired/deny`로 분류합니다.

workflow는 퇴역 안내 파일이 바뀔 때만 한 번 실행되며 모든 GitHub Action은 exact commit SHA로 고정합니다. 서비스 재활성화는 이 저장소의 목적이 아닙니다.
